# QR Code Generator

A simple Python script that generates QR codes from URLs and saves them as PNG files.

## Features
- Generate QR codes from URLs
- Save QR codes as PNG images
- Remembers your save path using `data.json`

## Requirements
- Python 3
- `qrcode` library

Install the library with:

```bash
pip install "qrcode[pil]"
```

## How to use
1. Run the script.
2. Choose where to save the QR code (only the first time).
3. Enter the URL.
4. Your QR code will be generated and saved!

**Note:** Keep `data.json` in the same folder as the script so your save path is remembered.
